# 永貞國小學生學習成果展
## 學生多元展能 × SDGs 永續校園 × 六年成長軌跡線上特展

本專案為 **苗栗縣頭份市永貞國民小學**（六年甲班，徐秉鴻老師班級）之學生學習成果線上特展。全站統整 15 個重大展能活動主題、113 張真實高畫質紀實影像，深度對接 108 課綱三面九項核心素養與聯合國永續發展目標（UN SDGs 3, 4, 10, 11, 12, 17）。

- **線上成果展網址**：https://binghong-xu.github.io/yongzhen-learning-showcase/
- **技術架構**：純 HTML5 + CSS3 (CSS Variables, Flexbox/Grid) + 原生 Vanilla JavaScript
- **相容性**：100% 響應式（RWD）相容手機、平板與桌機，支援零障礙嵌入 Google Sites。
- **資安合規**：100% 個資脫敏（零手機、零電話、零 Email）。

### 🌐 Google Sites 嵌入使用教學

本專案為純靜態網頁，無跨網域（CORS / X-Frame-Options）限制，非常適合作為 Google 協作平台（Google Sites）的特色成果區塊。

#### 方法一：依網址嵌入（推薦，最簡潔）
1. 開啟您的 Google 協作平台編輯頁面。
2. 於右側面板選擇 **「嵌入」** ➔ 選擇 **「依網址」**。
3. 貼上專屬網址：
   ```
   https://binghong-xu.github.io/yongzhen-learning-showcase/
   ```
4. 點選「插入」，調整區塊寬度為滿版、高度建議拉至 `850px` ~ `950px` 即可！

#### 方法二：依程式碼嵌入（可自訂圓角與邊框）
於右側面板選擇 **「嵌入」** ➔ **「嵌入程式碼」**，貼上以下代碼：

```html
<iframe 
  src="https://binghong-xu.github.io/yongzhen-learning-showcase/" 
  width="100%" 
  height="900" 
  style="border: none; border-radius: 16px; box-shadow: 0 8px 30px rgba(0,0,0,0.08); overflow: hidden;" 
  allow="fullscreen" 
  loading="lazy">
</iframe>
```

> [!TIP]
> 當網頁被嵌入至 Google Sites 的 `iframe` 中時，右上方導航列會自動出現 **「↗ 全螢幕」** 按鈕，方便訪客與評審委員一鍵在新分頁中展開沉浸式全螢幕檢視！
